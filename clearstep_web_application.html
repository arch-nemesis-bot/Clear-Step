Problem & System Architecture

How ClearStep Assists Daily Routines

Cognitive Disruption

Mid-task distractions can cause users with memory impairment to forget which step they were performing (e.g., whether pills were taken or toothpaste applied).

Local Vision Tracking

A local laptop webcam runs hand-tracking (MediaPipe) and object identification (YOLO-World/COCO). Video frames remain in local RAM and are never saved or sent online.

Dedicated ESP32 Edge Device

Receives state commands over USB Serial to update the OLED checklist display, operate the privacy servo shutter, and trigger subtle audio-visual cues.

Hardware Components Breakdown

Host Computer (Vision Processing) Laptop (AMD Ryzen 7)

Runs Python 3 OpenCV, MediaPipe Hand Landmark tracking, and YOLO object detection model locally in memory.

Microcontroller Edge Module ESP32 Development Board

Connected via USB Serial. Manages display rendering, hardware interrupts, and mechanical shutter actuation.

Monochrome Display 0.96" SSD1306 OLED (I2C)

High-contrast 128x64 display. Connected to ESP32 I2C pins (SDA: GPIO 21, SCL: GPIO 22).

Actuators & Physical I/O Servo, Button, LED, Buzzer

Micro Servo shutter (GPIO 13), Override Push Button (GPIO 12), Status LED (GPIO 14), and Piezo Buzzer (GPIO 27).

Real Technical Limitations & Specs

COCO Class Constraints: Standard COCO-pretrained models are limited to 80 general categories (e.g. cup, bottle, toothbrush). Custom items require fine-tuning or zero-shot models like YOLO-World.
Hand-Object Overlap Confirmation: Step verification requires sustained spatial overlap between the MediaPipe hand bounding box and target object for a minimum dwell duration (~5 consecutive frames).
Air-Gapped Privacy Guarantee: No video frames leave local RAM or host memory. Frame buffers are immediately overwritten after landmark processing.

Built-In Safety Engineering

Improvisations & Safety Protocols

Six fundamental safeguards built to prevent false positives, preserve privacy, and eliminate frustration.

1. Zero-Failure Tap

Physical push button override on the ESP32. If an object is occluded or vision detection fails, pressing the button manually checks off the active item without blocking progress.

2. Calm-Cue Guidance

Uses non-alarming soft LED pulses and low-frequency piezo chimes to guide attention back to skipped steps without triggering anxiety or confusion.

3. Opti-Privacy Lock

A micro-servo motor rotates a physical shutter panel in front of the camera lens when no routines are actively running, guaranteeing hardware-level privacy.

4. Context Rewind

Pressing and holding the override button allows the user to backtrack to previous checklist steps if an item was accidentally picked up or moved prematurely.

5. Shadow-Step Buffer

Requires multi-frame bounding-box overlap before confirming interaction, preventing accidental triggers when hands briefly pass over objects.

6. Watchdog Heartbeat

Serial heartbeat ping sent between Python host and ESP32. If connection drops, the OLED screen clearly displays a reconnection warning.
